# shared/ — code compiled into BOTH the frontend and the backend

Pure TypeScript only: no Babylon, no Node APIs, no DOM. Everything in here is
build-time shared source — the two deployables stay completely independent at
runtime (their only coupling is still `VITE_API_URL` / `FRONTEND_URL`).

How it reaches each side: `scripts/sync-shared.mjs` copies this folder into
`frontend/src/shared/` and `backend/src/shared/` (both git-ignored, both
regenerated by every `dev`, `build` and `typecheck` script). Each side imports
from its own copy with ordinary relative paths, so neither build needs any
alias, workspace or path trick. Edit files HERE, never in the copies.

Layout — one folder per game, mirrored on both sides:

    shared/core/               generic match protocol (events + payload shapes)
    shared/games/<gameId>/     that game's rules + deterministic simulation
